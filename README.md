# 배터리 허브 (BatteryHub)

제조사 상관없이 같은 와이파이에 있는 내 안드로이드 폰·태블릿과, 각 기기에 연결된 블루투스 이어폰·워치의 배터리를 홈 화면 위젯 하나로 보여주는 앱.

## 설치
1. [Releases](../../releases/latest)에서 `BatteryHub.apk`를 받아 모든 기기에 설치
2. 앱 실행 → 기기 이름 정하기 → **동기화 시작** → **배터리 최적화에서 제외하기**
3. 홈 화면 길게 누르기 → 위젯 → 배터리 허브 → **통합 배터리** 추가

## 동작 방식
- 각 기기가 1분마다, 그리고 잔량·충전 상태가 바뀔 때 UDP 브로드캐스트(포트 48821)로 자기 배터리와 연결된 블루투스 기기 배터리를 보냄
- 서버 없음 — 같은 와이파이 안에서만 동작
- 10분 넘게 소식이 없으면 회색 + 마지막 수신 시각, 3일 지나면 자동 삭제
